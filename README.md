# 两人账

夫妻二人一起记账、一起攒钱的 App。

- **同步记账**：两人各自记，实时同步。对方能看到金额和分类，**备注只有自己能看到**（服务器层面保证）。
- **攒钱目标**：两人分别填每月预期到手收入，再定攒钱目标，App 按「动态限额」算出每月能花多少。
  - 本月超支，之后几个月的限额自动收紧；本月省下来，之后的限额就宽松一点。
  - 收入按每人每月的实际到账修正：上个月的收入可以在次月 7 号前补记，过期没登记会按预期收入算；次月初还没登记时会弹窗提醒。
- **大件测算**：想买手机、电脑这类大件，先输入价格，看看本月额度、之后每月限额和攒钱目标会怎么变，并给出分摊建议。
  - 决定要买可以先「预扣」，两人都能看到买什么；不买就取消，买了只要点「已经买了」，不用再记一笔。
- **月度奖章**：上个月没超限额、攒钱也跟上了计划进度，下个月打开 App 时会发一枚奖章。
- **友情提醒**：本月花到 80%、100%、120%，以及整个计划期超支时，两人都会收到提醒。
  - 提醒文案可以自定义，支持 `{限额}`、`{还差}` 等占位符，发送时自动替换成实际金额。
- **收入和支出都能记**，没网时也能记，联网后自动上传。
- **三种使用方式**（公开版安装包首次打开时选择）：
  - **单机体验**：不需要服务器，数据只在这台手机上，用「TA（模拟）」代替另一半，先熟悉功能。
  - **两人同步**：不需要自己部署服务器。两台手机用配对码配对，账目只保存在两台手机上；作者的服务器只转交端到端加密的数据，送达就删除，看不到内容。超支提醒在打开 App 时弹出。
  - **使用自己的服务器**：数据存在你们自己部署的服务器上，App 关着也能收到超支提醒。

### 「两人同步」的数据在哪里

- 账目、目标、提醒文案：只保存在你们两台手机上。备注只在记它的那台手机上，**不会发给对方**。
- 作者的转发服务器：只暂存还没送到对方手机的**密文**，对方手机取走就删除，最多保留 30 天。服务器能看到的只有手机 IP、房间号、消息大小和收发时间，看不到金额、分类、备注等任何内容。配对码不经过服务器，作者没有办法解密。
- 换手机：在新手机上选「两人同步 → 我换了手机，要找回原来的账」，输入配对码（另一半在「我的 → 配对码」里能看到），账目会从另一半的手机上取回。旧手机上的备注找不回来。
- **两台手机都丢了，数据就没了**。服务器上没有可以恢复的副本。

## 下载安装

到 [Releases](../../releases) 下载 `liangrenzhang-<版本>-public.apk`（Android 8.0 及以上）。

- 打开后选「单机体验」，不需要服务器。
- 选「两人同步」，一个人创建后把配对码发给另一半，另一半输入配对码加入。
- 选「使用自己的服务器」，填你自己部署的服务器地址（部署方法见 [服务器部署](docs/服务器部署.md)）。

鸿蒙 NEXT 只能安装用开发者本人证书签名的应用，所以没有提供现成的安装包。需要从源码构建：先把包名改成你自己的（见下文「自己部署 / 二次开发」），再按 [鸿蒙签名与推送](docs/鸿蒙签名与推送.md) 签名，用 `tools/build-ohos.sh --public --install` 构建安装。这样装出来的和安卓公开版一样，打开后可以选单机体验、两人同步或自己的服务器。

## 目录结构

```
app/        Flutter 客户端（Flutter-OH，一套代码出 Android APK 和鸿蒙 HAP）
server/     服务端：PocketBase 扩展（Go）、「两人同步」转发服务（server/cmd/relay）+ Docker 部署脚本
shared/     服务端和客户端共用的预算计算测试用例
tools/      开发环境、构建、签名脚本
docs/       部署和安装说明
dist/       构建产物（镜像、安装包），不提交
```

## 常用命令

所有命令都在项目根目录执行。先加载开发环境（工具链默认在 `~/DevTools`，装在别处时见 `tools/dev-env.sh` 开头的说明）：

```bash
source tools/dev-env.sh
```

服务端测试：

```bash
cd server && go test ./...
```

客户端测试：

```bash
cd app && flutter test
```

构建 Android 安装包，产物在 `dist/android/`：

```bash
tools/build-android.sh
```

构建并签名鸿蒙安装包，产物在 `dist/ohos/`：

```bash
tools/build-ohos.sh
```

## 重要文件（务必备份，不在项目目录里）

| 位置 | 内容 |
|---|---|
| `~/.couple-ledger-ca/` | 自建根证书和私钥。App 用它校验服务器；迁移服务器时用它重新签发证书 |
| `~/.couple-ledger-keys/` | Android 和鸿蒙的签名密钥、密码。丢失后 App 升级前需要先卸载旧版 |

## 自己部署 / 二次开发

- 包名 `com.k1ngmew.liangrenzhang` 已被本项目占用。你自己发布时请换成自己的包名：Android 改 `app/android/app/build.gradle.kts` 里的 `namespace`、`applicationId` 和 Kotlin 包路径，鸿蒙改 `app/ohos/AppScope/app.json5` 里的 `bundleName`。
- 服务器地址、根证书、签名密钥、华为推送凭据都不在仓库里，按 `docs/` 里的文档自己生成。
- 公开版的「两人同步」默认用作者的服务器转发，地址和它的根证书（公开证书，不含私钥）在 `tools/relay/`，自己从源码构建也能直接用。想换成自己的转发服务器，见 [服务器部署](docs/服务器部署.md) 里的「转发服务」。
