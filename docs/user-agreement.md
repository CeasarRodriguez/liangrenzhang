## 一、本应用提供什么

本应用是供两个人（如夫妻、情侣）共同记账、攒钱的工具，免费使用，不含广告和应用内购买。你可以选择三种使用方式：

1. **单机体验**：数据只保存在你的手机上。
2. **两人同步**：通过配对码把两台手机连在一起。数据经我们运营的转发服务器以加密形式转交给对方手机，账目只保存在两台手机上。
3. **使用自己的服务器**：数据保存在你们自行部署的服务器上，由你们自己管理。

本应用是开源软件，源代码以 GPL-3.0 许可证公开。你使用和分发源代码的权利以该许可证为准。

1. **妥善保管配对码**。配对码相当于你们账本的钥匙，任何拿到配对码的人都可以加入并看到你们共享的账目。请只发给你的另一半，因你泄露配对码造成的后果由你自行承担。
2. **合法使用**。不得利用本应用或转发服务器从事违法活动，不得干扰、攻击、滥用转发服务器（例如大量发送无关数据、绕过频率限制），不得破坏本应用或转发服务器的正常运行。
3. **自行部署的服务器**。如果你使用「自己的服务器」，服务器的安全、备份、合规（包括所在地要求的备案）由你自行负责。
4. **自行备份重要数据**。两人同步模式下，数据只保存在你们的手机上，我们不保留可恢复的副本。如果两台手机上的数据都丢失（例如两台手机都丢失、都卸载或都解除配对），数据将无法恢复。

## 三、转发服务

1. 转发服务器只用于在两台配对的手机之间转交加密数据，看不到账目内容。对方手机取走后数据立即删除；超过 30 天未被取走的数据会被删除；长期不使用的设备和房间会被清理（具体期限见隐私政策）。
2. 为保证服务稳定，转发服务器对单次请求大小、待送达数据总量、每个房间的设备数量和请求频率设有限制。
3. 转发服务免费提供，我们会尽力保持其正常运行，但不承诺不中断。因维护、升级、网络故障、不可抗力等原因，服务可能暂停；服务暂停期间，你仍可以离线记账，恢复后会自动同步。
4. 如果我们决定停止提供转发服务，会提前在应用内或项目主页公告。停止后，你手机上的数据不受影响，可以继续使用单机方式，或改用自己的服务器。
