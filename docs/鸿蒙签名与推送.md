# 鸿蒙版：签名与推送配置

鸿蒙 NEXT 手机只能安装签过名的 App，后台推送还需要华为 Push Kit。这些都在华为 **AppGallery Connect（AGC）** 网站上配置，需要你登录自己的华为开发者账号来操作。

> 下面的菜单名称以 2026 年的 AGC 为准，如果华为改了界面，找名称相近的入口即可。

签名密钥和证书请求文件已经由 `tools/setup-signing.sh` 生成好了，位置如下：

- `~/.couple-ledger-keys/harmony/harmony.p12`：私钥，不要外传
- `~/.couple-ledger-keys/harmony/harmony.csr`：证书请求文件，等下要上传到 AGC

## 1. 手机打开开发者模式

1. 在鸿蒙手机上依次进入 **设置 → 关于本机**，连续点击「软件版本」7 次，直到提示已进入开发者模式。
2. 回到设置，进入 **系统 → 开发者选项**，打开「USB 调试」。
3. 用数据线把手机连到 Mac，手机上弹出「允许 USB 调试」时选择允许。
4. 在 Mac 上执行下面的命令，记下输出的 UDID：

   ```bash
   source tools/dev-env.sh
   ```

   ```bash
   hdc shell bm get --udid
   ```

## 2. 在 AGC 创建项目和应用

1. 打开 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，进入 **我的项目 → 添加项目**，项目名称填「两人账」。
2. 在这个项目里选择 **添加应用**，按下面填写：
   - 平台：HarmonyOS
   - 应用类型：应用（APP）
   - 应用包名：**`com.k1ngmew.liangrenzhang`**（必须和代码里的完全一致）
   - 应用名称：两人账
3. 进入 **项目设置 → 常规**，在「应用」区域找到 **Client ID**。把它保存成一个文本文件：

   ```bash
   echo "这里换成你的ClientID" > ~/.couple-ledger-keys/harmony/client_id.txt
   ```

4. 在项目里找到 **推送服务**（一般在「增长」或「开发」菜单下），点击开通。

## 3. 申请调试证书和 Profile

1. 进入 **证书、APP ID 和 Profile → 设备 → 添加设备**：
   - 类型选「手机」
   - 填入第 1 步记下的 UDID
2. 进入 **证书 → 新增证书**：
   - 类型选「调试证书」
   - 上传 `~/.couple-ledger-keys/harmony/harmony.csr`
   - 生成后下载，保存为 **`~/.couple-ledger-keys/harmony/debug.cer`**
3. 进入 **Profile → 添加**：
   - 应用选「两人账」，类型选「调试」
   - 证书选上一步生成的调试证书，设备勾选你的手机
   - 生成后下载，保存为 **`~/.couple-ledger-keys/harmony/debug.p7b`**

> 调试证书和 Profile 大约一年过期。过期后按本节重新申请、重新安装即可，数据都在服务器上，不会丢失。

### 备案要用的发布证书

App 备案要填公钥和证书 MD5 指纹，这两项必须从**发布证书**里提取，调试证书不能用。

1. 在 **证书 → 新增证书** 里选「发布证书」，上传的还是同一个 `harmony.csr`。
2. 生成后下载，保存为 **`~/.couple-ledger-keys/harmony/release.cer`**。
3. 从证书文件中提取公钥和 MD5 指纹（文件里有三张证书，用最后一张，也就是你自己的那张）：

   ```bash
   awk '/BEGIN CERT/{n++} n==3' ~/.couple-ledger-keys/harmony/release.cer | openssl x509 -noout -fingerprint -md5 -pubkey
   ```

申请发布证书不需要手机 UDID。

## 4. 构建、签名并安装到手机

手机保持用数据线连接，执行：

```bash
tools/build-ohos.sh --install
```

脚本会依次完成：

1. 构建安装包，并自动填入 Client ID
2. 用你的证书签名
3. 通过 hdc 安装到手机

签好名的安装包保存在 `dist/ohos/`。

上面的命令会打包 `server/deploy/.env` 里你自己的服务器地址。没有自己的服务器时，改用公开版，打开后可以选「两人同步」（用作者的服务器转发加密数据）或单机体验：

```bash
tools/build-ohos.sh --public --install
```

## 5. 服务器端推送凭据

服务器调用华为推送接口时需要凭据，下面两种方式任选一种，填进 `server/deploy/.env`。

**方式一：OAuth 客户端（推荐，最简单）**

1. 在 AGC 进入 **项目设置 → 常规**，记下项目区域的「项目 ID」。
2. 在 **项目设置 → API 客户端**（或「Server SDK」）里创建一个客户端，记下它的 Client ID 和 Client Secret。
3. 按下面填写 `.env`：

```
HUAWEI_PROJECT_ID=项目ID
HUAWEI_CLIENT_ID=API客户端的ClientID
HUAWEI_CLIENT_SECRET=API客户端的Secret
```

**方式二：服务账号密钥**

1. 在 **项目设置 → 服务账号** 里创建服务账号，下载 JSON 格式的密钥文件。
2. 把文件放到 `server/deploy/secrets/huawei-service-account.json`。
3. 按下面填写 `.env`：

```
HUAWEI_PROJECT_ID=项目ID
HUAWEI_SERVICE_ACCOUNT_FILE=/app/secrets/huawei-service-account.json
```

改完重新部署：

```bash
server/deploy/deploy.sh root@服务器IP 1.0.0 linux/amd64
```

关于下面两项配置：

- `HUAWEI_PUSH_CATEGORY=MARKETING`：资讯营销类消息，不需要额外申请权益。
- `HUAWEI_PUSH_TEST_MESSAGE=true`：以「测试消息」方式发送，没有上架的调试版 App 需要这样才能收到。

这两项保持默认即可。

## 6. 验证推送

1. 在鸿蒙手机上打开 App，登录后在「我的 → 通知设置」里允许通知。App 会自动把这台手机登记到服务器。
2. 把 App 从后台划掉。
3. 让另一半记几笔账，使本月支出超过限额的 80%。
4. 鸿蒙手机应该收到「本月预算已用八成」的通知。

如果没收到，可以在服务器上看日志，搜索 `harmony push failed`：

```bash
ssh root@服务器IP "cd /opt/couple-ledger && docker compose logs pocketbase | grep -i push"
```
