# 安装到手机

安装前请先确认两件事：服务器已经部署好（见 [服务器部署](服务器部署.md)），并且 `server/deploy/.env` 里的服务器地址填对了。

构建脚本会自动把下面两样东西打包进 App：

- 服务器地址
- 根证书 `~/.couple-ledger-ca/ca.crt`

## 两种安装包

| 构建命令 | 产物 | 适合 |
|---|---|---|
| `tools/build-android.sh` | `liangrenzhang-<版本>-release.apk` | 自己用：内置你的服务器地址和根证书，打开就是登录页 |
| `tools/build-android.sh --public` | `liangrenzhang-<版本>-public.apk` | 公开发布：不含自己服务器的地址和证书；「两人同步」默认用作者的服务器转发 |

公开版第一次打开时，可以选三条路：

- **单机体验**：不需要服务器，数据只存在手机上，用「TA（模拟）」代替另一半。超额提醒以 App 内弹窗的形式出现。
- **两人同步**：不需要服务器。一个人创建后把配对码发给另一半，另一半输入配对码加入。账目只存在两台手机上，作者的服务器只转交加密数据、看不到内容。超额提醒在打开 App 时弹出，没有后台通知。
- **使用自己的服务器**：填自己部署的服务器地址，App 关着也能收到超支提醒。服务器用的是自建证书时，App 会显示证书指纹，让你和服务器上的指纹核对一次（类似第一次 SSH 登录），核对一致才信任。服务器上查看指纹：

  ```bash
  openssl x509 -noout -fingerprint -sha256 -in /opt/couple-ledger/data/certs/server.crt
  ```

几种方式可以随时切换：单机体验时在「我的」页面；两人同步时在「我的 → 换一种使用方式」；登录页下方也有入口。每种方式的数据分开存放，互不影响，体验数据不会上传。

## vivo / iQOO（Android）

1. 构建安装包：

   ```bash
   tools/build-android.sh
   ```

   产物是 `dist/android/liangrenzhang-<版本>-release.apk`。
2. 把 APK 发到手机上，用微信文件传输助手、数据线拷贝都可以，然后点开安装。系统提示「未知来源」时选择允许。
3. 打开 App 后，先完成以下配对：
   1. 注册账号
   2. 创建家庭，把邀请码发给另一半
   3. 另一半注册后选择「加入」，输入这个邀请码
4. **一定要做**：进入「我的 → 通知设置」，按页面引导完成三步：
   - 允许通知
   - 关闭电池优化
   - 在 vivo 设置里打开「允许后台高耗电」和「自启动」，并在最近任务里把两人账锁定

   做完这几步，App 关着时也能收到超支提醒。通知栏会常驻一个「正在守护你们的小金库」的小图标，这是正常的。

以后升级 App，直接覆盖安装就行，数据不会丢。

## 鸿蒙 NEXT

见 [鸿蒙签名与推送](鸿蒙签名与推送.md)：配置一次签名证书后，执行下面的命令就能装到连着电脑的手机上：

```bash
tools/build-ohos.sh --install
```

没有自己的服务器、想用「两人同步」或单机体验时，装公开版：

```bash
tools/build-ohos.sh --public --install
```

## 换了服务器之后

在两台手机上都进入「我的 → 服务器地址」，改成新地址即可，不需要重新安装。迁移方法见 [服务器部署](服务器部署.md#迁移到新服务器)。
