# App 图标

图标的源文件是 `design/icon_foreground.png`：透明背景的小猪存钱罐，背景色用的是奶油色 `#FFF1E6`。

用这个源文件生成以下几处图标：

- Android：普通图标，以及自适应图标（前景层 + 背景色）
- 鸿蒙：分层图标（前景层 + 背景层）和普通图标
- 登录页 logo：`app/assets/logo.png`

## 更换图标

1. 用新图覆盖 `design/icon_foreground.png`。要求是透明背景，尺寸至少 1024×1024。
2. 重新生成各平台的图标。这一步需要 Pillow，可以先执行 `python3 -m pip install pillow` 安装：

   ```bash
   python3 tools/make-icons.py
   ```

3. 重新构建 App，新图标就会生效。

## 当初用的提示词（备查）

> 扁平化手机 App 图标，一只圆润可爱的小猪存钱罐，由两颗交叠的爱心组成，顶部有一枚金色硬币正在投入。暖色调：珊瑚粉 + 奶油黄 + 少量薄荷绿点缀。简洁几何造型，柔和圆角，无文字，无阴影杂讯，居中构图，主体占画面 60%，纯色浅暖背景，1024×1024，现代极简风格。

## 华为应用市场（AppGallery）的商店图标

上架时要单独上传一张应用图标，要求：正方形 1024×1024 或 216×216、PNG、不透明、不带圆角（商店会自己加圆角蒙层），并且和安装包里的图标一致。

`design/appgallery_icon_1024.png` 和 `design/appgallery_icon_216.png` 就是按这个要求生成的：画面和鸿蒙安装包里的分层图标完全相同（奶油色铺满背景，小猪占 62%）。换图标后重新生成：

```bash
python3 tools/make-icons.py --store
```
